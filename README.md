# 🛡️ ربات گارد تلگرام — نسخه فاز ۱

این نسخه شامل قابلیت‌های **مرحله ۱** از لیست کامل شماست:
- خوش‌آمدگویی و خداحافظی قابل تنظیم
- سیستم امتیاز ساده (Leveling) بر اساس تعداد پیام
- ضداسپم پایه: فیلتر کلمات ممنوعه، فیلتر لینک، محافظت در برابر Flood
- قفل/باز کردن گروه
- دستورات ادمین: warn/mute/kick/ban و ...

قابلیت‌های مراحل ۲ و ۳ (امنیت پیشرفته، سیستم تشویق کامل، ابزارهای مدیریتی،
گزارش‌گیری، ویس‌کال، مالی، هوش مصنوعی) در این نسخه نیستند — این‌ها هرکدام
پروژه‌ی جداگانه‌ای هستند و باید مرحله به مرحله روی همین اسکلت اضافه شوند
(پایین صفحه توضیح داده شده).

---

## ۱. پیش‌نیاز
- Python 3.10 یا بالاتر
- یک توکن ربات از [@BotFather](https://t.me/BotFather)
- آیدی عددی خودتان از [@userinfobot](https://t.me/userinfobot)

## ۲. ساخت و فعال‌سازی محیط مجازی (venv)

### Linux / macOS
```bash
python3 -m venv venv
source venv/bin/activate
```

### Windows (PowerShell)
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

بعد از فعال شدن، جلوی خط فرمان `(venv)` را می‌بینید.

## ۳. نصب کتابخانه‌های مورد نیاز
```bash
pip install -r requirements.txt
```

این دستور دو کتابخانه را نصب می‌کند:
- `python-telegram-bot==21.4`
- `python-dotenv==1.0.1`

## ۴. تنظیم فایل env
```bash
cp .env.example .env
```
سپس فایل `.env` را باز کنید و مقادیر زیر را با اطلاعات خودتان جایگزین کنید:
```
BOT_TOKEN=توکن ربات شما از BotFather
OWNER_ID=آیدی عددی شما
```

## ۵. اجرای ربات
```bash
python main.py
```
اگر پیام `Bot starting (polling mode)...` را دیدید، ربات آنلاین است.

## ۶. اضافه کردن ربات به گروه
1. ربات را به گروه اضافه کنید.
2. آن را **ادمین** کنید و حتماً دسترسی‌های زیر را فعال کنید:
   - حذف پیام‌ها (Delete messages)
   - بن/سکوت کاربران (Ban/Restrict members)
   - پین کردن پیام‌ها (Pin messages)

بدون این دسترسی‌ها، دستورات مربوطه با خطا مواجه می‌شوند (نه کرش می‌کند، فقط
همان بخش کار نمی‌کند).

## ساختار پروژه
```
telegram_guard_bot/
├── main.py              # نقطه ورود، ثبت همه‌ی هندلرها
├── config.py            # خواندن متغیرهای محیطی
├── database.py          # لایه‌ی دیتابیس (SQLite)
├── requirements.txt
├── .env.example
├── handlers/
│   ├── general.py       # دستورات عمومی (/help, /stats, /top, ...)
│   ├── welcome.py        # خوش‌آمد/خداحافظ + امتیازدهی
│   ├── antispam.py       # فیلتر کلمه/لینک/فلود/قفل گروه
│   └── admin.py          # warn/mute/kick/ban/تنظیمات
└── utils/
    └── permissions.py    # چک ادمین بودن کاربر
```

## چرا SQLite به‌جای PostgreSQL+Redis؟
برای فاز ۱، SQLite نیاز به هیچ سروری ندارد و همین الان قابل اجراست.
وقتی گروه شما بزرگ شد یا خواستید Scale کنید، فقط کافیست فایل `database.py`
با یک نسخه‌ی SQLAlchemy/PostgreSQL جایگزین شود — بقیه‌ی کد (handlers) دست
نمی‌خورد، چون فقط با توابع این فایل کار می‌کنند، نه مستقیم با SQL.

## نکته درباره‌ی «تشخیص اسپم با AI»، ویس‌کال، سیستم مالی و امنیت پیشرفته
این‌ها هرکدام نیاز به سرویس‌های جانبی دارند (مثلاً pytgcalls برای ویس‌کال،
یک مدل AI برای تشخیص اسپم هوشمند، دیتابیس تراکنش برای بخش مالی). پیشنهاد
می‌شود این‌ها را یکی‌یکی به‌عنوان ماژول جدا به همین اسکلت اضافه کنیم تا هر
بخش قبل از رفتن به مرحله بعد، واقعاً تست و تأیید شود.
